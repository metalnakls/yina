# yina 5.2

- Enable sharing from the movie already open, without choosing its folder again. Existing shared-room identity is reused.
- Discover live hosts in the welcome window’s Already watching section and join directly.
- Send live playback controls between Macs over the local network. Both host and client can play, pause, seek, and change speed while staying in the session.
- Keep media on the shared drive and preserve saved progress and room identity in `.yina/`.
- Show connection and media-location feedback when joining a room.

Both Macs need this version, Local Network access, and access to the shared media. Independent-process Bonjour and real-mpv tests passed; a physical two-Mac SMB session remains to be verified.
